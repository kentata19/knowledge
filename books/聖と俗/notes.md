## 第6章　求道者としてのテレクラ修行──ナンパ師時代

定住以前はモノガミー(1対1)で番って子をもうけ、その子が3歳を超えると関係が解消され新たな相手と番って子をもうけていた。
しかし定住が開始される。定住を支える農耕には種蒔きから収穫までの手順の定め、協働の定め、収穫物の保全・配分・継承の定めがいるので「言語」で語られた「法」に、罰を嫌がる「損得勘定」で従うという法生活が始まった。
この法の中に収穫物の所有や土地の所有の継承線を定めるべく番とは違って永続規範を伴う結婚が書き込まれた。
人々は従来にないこの法生活で「力」を失う。定住を拒む非定住民が生まれる。所有をあえて拒むからこそ差別される。
他方、定住民は失われる力を回復すべく定期的に祝祭し、そこに定住以前の作法を知る被差別民を召喚する。
この力が湧く時空が「聖」。力を使う時空が「俗」。したがって、召喚される非定住民は「聖」である。
この祝祭の核は法的タブーの反転(結婚と乱交)

ナンパ師は様々な手段で相手を変性意識状態に陥らせる。
ex.支離滅裂なマシンガントーク、自分が感じる世界を誰よりも同じように感じてくれる

スワッピンはあくまでカップルへの力の注入。夫婦や恋人同士が抑制された頻度で参加して嫉妬を体験する。<->乱交party
「関係性のゲーム」<->「フェティシズムのゲーム」
ただこの嫉妬は、男性的な「裏切られた怒り」や、女性的な「取られた怒り」ではなく、「恋人に享楽を与える(ことで享楽する)相手がなぜ自分ではないのか」という嫉妬。
これを通じて「自分の愛を確かめる」営み。

## 第7章　援助交際ブームとは何だったのか──援交フィールドワーク時代

旧枢軸国(ドイツ/日本)では崇高な秩序との一体性を尊厳とみなし、旧連合国では自由な試行錯誤で得た自己信頼を尊厳とみなす。
ここで、初期の自由な試行錯誤を妨げる尊厳規範を回避すべく、自由な試行錯誤の保護の観点から附従契約が生じやすい低年齢売春を規制する。

## 第8章　「終わりなき日常は地獄である」──メディアの寵児に

1980年~新住民化: 土地に縁なき転入者の多数派化。安全・便利・快適化。
こうして街の営みが反転する。カテゴリーを超えてフュージョンする営み => カテゴリーにステレオタイプを結合する営み(うちは分譲だから賃貸の子と遊んじゃダメ的な)
これにより子供たちから身体的なりきり(アフォーダンス - 気がつくと体が動いている)と感情的なりきり(ミメーシス - 気がつくとその人に感染して感情が動いている)の能力が奪われる(遊び相手がラベルで選別されれば同質な相手しか残らず、なりきる必要がなくなる)
この2つのなりきりが、言外・法外・損得外でシンクロする能力の土台になっている。
そしてこのシンクロ能力を前提とする、「社会で疲れて帰還したあと力を充填して社会に出撃する営み」を支えるホームベースが大人から失われた。

このホームベースの営みは、「社会」に対して、言外・法外・損得外が優位する「社会の外」を成す。
ここでは、仮に社会で不適切な振る舞いも、全人格的な関係の履歴が与える人格的信頼ゆえに、「またパパったら」という感情的包摂を与える。
この感情的包摂の機能を果たす関係性があれば、たとえ共住共食や血縁がなくても「家族的」と言える。

力の回復や授受には、ブーバーが言うところの「置換可能なソレ」ならぬ「置換不能な汝」として眼差される必要がある。事と次第で供給が止まる市場と行政にはその役割は任せられない。
そうすると、「社会が許さなくても私は許す」と言うアジール機能で定義されるルーマンの枠組み(家族は成員を役割ではなく全人格として包摂する)が、家族に「成員に力を回復する機能」と「新成員に力を授ける機能」を残すべきだと言う必然的な結論になる。前者が大人にとってのホームベースで、後者が子供にとってのなりきりの訓練場である。

→ 第6章の枠組み（力が湧く時空が「聖」、力を使う時空が「俗」）で言えば、ホームベースが「聖」、社会が「俗」。新住民化とは「聖」の側が消えて「俗」だけが残った過程だと読める。

以上を踏まえると、この新住民化が性愛能力を奪ったと言える。
性愛とは性欲に駆動された営み総体で、「恋愛」はその一部。
唯一性規範(あなたが世界のすべて)と贈与規範(あなたのためなら法も破る)を伴う営み。

システム論の人格モデルについて、今の社会は複雑で期待外れは自己像(self)に影響する。
「自己像が行為を方向づけ、その行為の成否が自己像を変容させ、その自己像が行為を方向づける」という循環がある。
行為の成否に関わる期待外れを自己像にフィードバックする方法は論理的に5つ。
どの方法を使うかで人格類型を分類できる。

1. 期待水準を予め低く設定し期待外れに免疫を作る: ニヒリスト
2. 期待水準を予め高く設定し期待外れに規範的に臨む(許せない): バンカラ
3. 情報感度を研ぎ澄まし期待はずれが起きないようにする: ミーハー
4. 期待外れが起きそうな領域から撤退する: ネクラ
5. 情報感度が優れた友人にくっついて模倣する: ヨリカカリ

人格の独自性は錯覚。5部品×各4状態なら全体は1024通りで多様に見えるが(数字は例示)、部品ひとつは4状態しか持たない凡庸な要素。限界状況での振る舞いを見れば、人が生体防衛のための単純な心的システムを備えていることは自明。
だからフロイトは self(像や物語である自己＝現象学の経験的自我)と ego(生体防御装置＝超越論的自我)を分けた。ego は self を維持することで極端な反応を回避させる。宮台語では「人格(意識システム)」＝ego、「自己のホメオスタシス」の自己＝self。
表現の授受も、ジャンルや芸術/芸能の別に関係なく「自己像維持に資するか否か」で選ばれる。何が有効かは、人格の環境＝社会や時代で変わる。

では、その自己像の型はどこから来るか。
〈世界〉(あらゆる全体＝physis)は直接体験できない。人が知るのは、人格システムと社会システムの関数である〈世界体験〉だけ(ユクスキュルの環世界論＝ミミズと人の世界体験は比較不能)。生活形式が違えば世界体験も違う。
人は本能未然(ネオテニー)で生まれるので、足りない生得プログラムを社会の習得プログラム＝型が埋める(ポルトマン)。ならば世界体験は無限に多様化しそうだが、そうならない。その歯止めを、言語ゲーム論は生活形式の家族的類似に、ユングは集合無意識の元型に見る(型を刻んだ先人だけがサバイブしたという進化的事実。ラカンの現実界とは説明の筋が違うだけで矛盾しない)。
これは ユクスキュル→シェーラー→ポルトマン→ゲーレン→ルーマン の「型による負担免除」論の系譜。型は人を縛るものではなく、負担を免除するもの。
だから型は表現者から「力」を奪わない。「型を知り、型を越える」自由が実存的指針。

→ 構造の整理(本文にはない読み筋):

問いの連鎖として読める。
Q1 人は多様に見えるのに、限界状況では数パターンに収束する。なぜか
   A 部品は凡庸。組み合わせの数だけが多い(4^5＝1024)
Q2 なぜ部品はそんな凡庸な処理しかしないのか
   A 部品＝ego の防衛操作だから。self を守る処理は論理的に5つ
Q3 ではその self の中身、期待水準はどこから来るのか
   A 社会が供給する型。人は〈世界〉ではなく〈世界体験〉しか持てず、それを型が構造化している
Q4 型は社会ごとに無限に多様化しないのか
   A しない。生活形式の家族的類似と元型(型を刻めた者だけが生き延びた)
Q5 型に従うのは力を奪われることではないのか
   A 逆。型は負担免除。浮いた力を勝負所に回すための装置
結論 型を知り、型を越える

二層構造になっている。内側は形式(誰でも同じ5操作)、外側が内容(何を期待し、何を成功とみなすか)を配る。

```
┌─ 外側の条件(Q3・Q4) ───────────────────┐
│  社会 ── 型 ──→〈世界体験〉の構造              │
│                    │                          │
│                    ↓ 期待水準・成功の定義を供給   │
│  ┌─ 内側の循環(Q1・Q2) ─────────────┐  │
│  │  期待 ─(外れ)→ ego の5操作 → self の変容 │  │
│  │        ↑                      │        │  │
│  │        └───── 行為の方向づけ ←──┘        │  │
│  └──────────────────────────┘  │
└────────────────────────────────┘
```

前節の5類型は、この内側ループの部品カタログ。5操作は論理的網羅なので、期待外れの処理から話を始めている。だが期待外れは期待がなければ存在せず、その期待は型が決めている。Q3以降は循環の外側にある期待の供給元を遡っている。

この構造の要は「二重の少なさ」。操作の少なさ(論理的に5つ)と中身の少なさ(供給元が少ない)を掛けて初めて「多様に見えて凡庸」が成立する。片方だけなら「中身は無限だから個性はある」で逃げられる。
また ego と型は同じ「負担免除」の内と外。ego は起きた期待外れの衝撃を吸収し、型は期待外れが起きにくいように世界体験を予め切り分ける。フロイトが個体の内部に見た防衛装置を社会の側に置き直したのが型論の系譜。
そして順序が肝。解体しきった後だから型の擁護が反転として効く。順序が逆(擁護から始める)なら伝統主義、解体だけで終われば虚無になる。

第6章とも繋がる。祝祭＝法的タブーの反転(結婚⇄乱交)は型の反転であり、型を持つ者だけが反転を体験できてそこで力が湧く。
