# ビデオニュース・ドットコム

## これは何か

真に独立した公共的な報道を行う目的で1999年に開局した、日本初のニュース専門インターネット放送局。広告に依存しないために開局当初からサブスクリプション制を採り、視聴には月額1,100円（税込）の会員登録が必要（一部無料放送あり）。各放送は原則として放送開始から3か月間オンディマンド公開される。

出典: [ビデオニュースについて](https://www.videonews.com/about)

## 主な番組

- **マル激トーク・オン・ディマンド** — 2001年4月開始。毎回キーパーソンをスタジオに招き、ジャーナリストの神保哲生と社会学者の宮台真司がニュースの核心を掘り下げる。金曜が5回ある月の5回目の金曜日は「5金スペシャル」として特別企画を**無料**で放送する。
- ニュース・コメンタリー / プレスクラブ / インタビューズ / スペシャルリポート ほか。
