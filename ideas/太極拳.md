# 太極拳（映画のタネ）

祖母が太極拳の先生をしていることを起点にした映画の企画メモ。
[[media/ビデオニュース・ドットコム/映画特集]] と `books/` の読書メモを材料にしている。回数の参照は映画特集ファイルの各回アンカーに対応。

記法: `> ` 引用 / `→ ` 自分の解釈 / `? ` 疑問

## 現在の方針

**30分の中編。コメディ。**

条件プログラム（「こうすればこうなる」）で生きた結果、症状は改善せず、仕事は回らず、彼女は他の男といる。
好きで撮っていた映画は、いつのまにか「**監督になれば会社を辞められる**」という脱出の条件に変わっている。
休職中、その休職をタスクで埋めるために、**祖母の太極拳を「取材」しに行く。**
父方の祖父母。父は数年前に亡くなっている。祖母は78で今が一番楽しい。**祖父は、亮の未来の形をしている。**

参照: 『川の底からこんにちは』（2010・石井裕也）— **ダサいものに全力を注ぐと人は泣く**／「中の下」の開き直り。
参照: 『生きちゃった』（2020・石井裕也）— 本当のことを言えない男と、その帰結。

## 全体を貫く一語＝「先回り」

| どこで | 先回り |
| --- | --- |
| コンビニ・会社 | **世界が彼の言葉を先回りして埋める** |
| 彼女 | **彼が彼女を先回りして手順化する** |
| 浮気 | **彼が対処法を先回りして練習する** |
| **カメラ** | **見る前に枠を決める。企画書・構成案・質問リスト** |
| 祖父 | **彼が祖父を先回りして「外に出す手順」で扱う** |
| **推手** | **先回りした瞬間に、崩される** |

**推手は比喩ではなく、先回りを禁じる物理的な訓練である。** これで太極拳が装飾ではなく機構になる。

→ 先回りは**症状**であって病名ではない。病名は**〈我とそれ〉＝互いを入れ替え可能な役割として扱うこと**。店員が先回りするのは、目の前にいるのが人ではなく「客」だから。**取材とは、対象を〈それ〉にする行為である。**

同じ法則が三回起きる。

| | やること | 結果 |
| --- | --- | --- |
| **喉** | 出そうとする | 出ない |
| **彼女** | 繋ぎとめようとする | 離れる |
| **カメラ** | 撮ろうとする | **一番いい瞬間は、撮らなかった瞬間** |

**努力が原因である。** 北風と太陽であり、中動態（第847・860回）。
観客は亮より先に気づく。**必死になるほど失う。**

（→ 映画特集の「条件プログラムと目的プログラム（主知主義と主意主義）」は9回に登場。1260/1234/1099/1073/1021/973/886/860/847）

## 確定した設定

### 症状

**吃音的なつっかえ。** 声が出ないのではなく、最初の音が繰り返す・止まる。
「黙っている人」は考えている人にも見えるが、**つっかえる人には逃げ場がない。**

### 規則＝「見られながら、役割として発話するとき」

> **よく知らない人たちに見られながら、役割として何かを伝えなければならないときだけ、つっかえる。**

- **店先**（店員＋後ろの列）／**大勢の前での発表**→ **出る**
- **1対1**（検査室、二人きり）→ **出ない**
- **家族・恋人・旧友**〈汝〉→ **出ない**

根にあるのは〈我とそれ〉（[[books/我と汝]]。映画特集1160、各回の「リプレースアビリティ」）。そこに**見られている（スペクタクル）**が重なったときだけ喉が閉じる（映画特集1121「見る・見られる／見世物」）。

**検査室では、全部できてしまう。** → **症状を、症状が出ない場所でしか説明できない。証明する手段がない。** → 「異常なし」。**恥はここで完成する。**

| | 何が起きているか |
| --- | --- |
| **外（店・会議）** | **彼が〈それ〉にされて、見られて、声が出ない** |
| **家（みなみ）** | **彼が彼女を〈それ〉にしていて、声は出るのに何も届いていない** |
| **カメラ** | **彼が祖母を〈それ〉にしようとして、祖母に乗っ取られる** |

彼は家では流暢である。**それでも本当のことを一度も言わない。** 沈黙は症状ではなく選択。
**カメラの後ろは、役割として喋らずに済む場所。** 彼が「撮る側」を選んだ理由に、観客は途中で気づく。

| 帰り際の卵焼き（二人きり） | × | **出ない** |

### 職業と映画

**エンジニア。条件分岐で世界を書く人。** 説明は一行（モニター二枚、issue、MGR会）。

**映画は「夢」ではない。手順である。** 「夢」という語は誰にも言わせない。
彼は映画を作ろうとしているのではなく、**映画を「処理」しようとしている。** issueを切るのと同じ手つきで企画書を書く。
- 撮る前にISO・シャッター・WBを詰めている。**祖母はもう喋り始めている**
- 撮影リストにチェックボックス。**祖父の「バッ」は、リストにない**
- 症状のスプレッドシート／撮影リスト／みなみへの「①まず聞く」——**全部同じフォーマット**

**好きだったものが、脱出の条件になった。** これをセリフなしで植える（下記①〜⑤）。

### 敵＝〈我とそれ〉。その見え方が「先回りして埋める」

**悪人ではなく、親切な人たち。** コンビニ「あ、大丈夫ですね」／会社「あ、じゃあ僕から」。**善意で殺される。**
教室が最初〈それ〉であることの印はカテゴリー。大西さんは彼を「**若いの**」としか呼ばない。

### トシ（祖母・78）

**とても可愛がる。好奇心旺盛で何でもやる。おしゃべりで笑顔が絶えない。元保育園の園長。**
料理教室、和楽踊り、フラダンス、太極拳。冷蔵庫のカレンダーがびっしり。**仲間がいる。「今が一番楽しい」。**

- **人を連れ出す、並ばせる、取り上げる。** 園長の手癖。スマホもカメラも、園児のおもちゃのように取り上げる
- **理由を聞かない。** 「なんで休職したの」が一切ない。「きっかけ？ なかったよ」
- **撮られるのが大好き。** カメラに手を振る。全員を紹介する。**演出し始める。被写体が映画を乗っ取る**——推手そのもの
- **どこにも行くためにやっていない。** 料理教室もフラも太極拳も。**亮のカメラは、どこかへ行くためのもの。** 隣に立たせれば、説明なしで見える
- **賢者ではない。** 助言をしない。孫の話を聞きながら柿の話をする。それで彼は楽になる

→ **「条件プログラムの外側」を理論ではなく、何でもやる・理由を聞かない・予定がびっしり、で体現する。**

### 祖父（81）

**寡黙で真面目。時々ユーモア。** 唇を閉じて、一気に開けて「**バッ**」——それで人を笑わせる。
友達と遊びに行かない。**家で一人、新聞とテレビ。** カレンダーの祖父の欄は空白。
**認知症気味。** 同じ話をする。**亮と弟（タクミ）をごっちゃにする。** 鍋を火にかけたまま寝る。

→ **亮は、若い祖父である。** 寡黙。家。画面。同じ手順の反復。人と会わない。サングラスとマスク。**この映画の本当の鏡。**
→ 祖父は取材対象ではない。だから亮は**祖父を画角から外し続ける。** 新聞を読む背中が、いつも端に入ってくる。**この映画の本当の主題は、彼が切り続けているものの中にいる。**
→ **「バッ」は言葉ではない音で人を笑わせる。** 亮の問題が言葉であることの、静かな対。

### 推手を三回、同じアングルで

**亮の変化を測る計器。説明はゼロ。**

1. **①（19）** 構えて、読んで、踏ん張る。**一瞬で崩れる。** トシは笑って次へ
2. **②（28）** 力を抜こうと"意識"している。顔に力が入っている。崩れる。トシ「**まだ考えてる**」
3. **③（32）** 何も考えていない。**崩れない。数秒続く。** **トシは褒めない。** 次へ

→ **推手③は「カメラを置く」（31）の後に置く。** 上達が悟りに見えないように。

### 映画の動作＝「待つ」

先回りして埋める世界の中で、待つ人だけが彼に届く。23で全員が待つ → 35で全員が待つ。

### トーンの原則

> **亮の内面をシリアスに撮らない。彼の必死さを笑う。**
> **ただし、周りが彼を笑う場面は一つも作らない。**
> **劇中の「映画」を作品として一度も見せない。** 企画書とカメラだけ。編集する場面も、誰かに見せる場面も作らない。「映像作家の苦悩」は禁止。

## 守る罠

- **治癒譚にしない。** 声は戻らない。会社も辞めない。**歌えることを「回復」として撮らない。**
- **「夢」を言わせない。** 映画は手順。「監督になりたい」は誰の口からも出ない。植えるのは退職シミュレーションと応募要項だけ。
- **劇中の映画を見せない。** 企画書とカメラだけ。編集も上映もない。
- **トシを賢者にしない。** 助言をしない。柿の話をする。**撮られると演出し始める。**
- **祖父を「可哀想な老人」にしない。** 「バッ」で人を笑わせる。**祖父は亮の鏡であって、教訓ではない。**
- **みなみを悪者にしない。** 疲れているだけ。
- **新興宗教を嘲笑しない。** 亮は本当に救われかけている。**ステップがあるから効かない。**
- **太極拳を神秘化しない。** 月謝千円、文句を言う82歳。
- **劇中の誰も亮を笑わない。** 笑うのは観客だけ。
- **説明しない。** スマホを取り上げる／腕を押さえる／カメラを床に置く／カメラを下ろす。**セリフより動作。**

## 検討したが入れなかったもの

- **祖母を施設に入れる説得** — 実在の祖母と合わない（元気・はっきり・社交的）。「母親は何をしているのか」の穴も埋まらない。取材の体裁に置き換えた。
- **母の電話で呼び戻される構造** — 亮が受け身のまま。取材は**自分の意志で、自分の手順で**行く。母はLINE一行（「おじいちゃん、最近ちょっとね」）に。
- **「嫁の言うことは聞かない」** — 祖父の人格と合わない。削除。
- **公園の許可制・署名・区役所（法化）** — 冗長。外敵は主人公の内側に葛藤を作らない。
- **医師の「イソップ、好き？」** — つまらない。「会社で録ってきてください」に。
- **トシが風呂場で転ぶ／「行くよ」** — 転倒は脚本自身の条件プログラム。
- **祖母が「ヒロシ」と呼ぶ** — トシは意識がはっきりしている。名前の混同は祖父の側（「タクミ」）に移した。
- **「佐野さん」ギャグ／老犬／河原で絶叫／飲み会／区民まつり／オデュッセイアの寝台・傷跡** — 以前の稿で削除。
- **祖父を病院に連れて行くミッション** — 亮の検査と鏡になるが、祖父母を医療化しすぎる。「外に出す」に。
- **祖母が撮った亮の映像を後で回収する** — 説明になる。⑤はそれ以上使わない。

## 残っている問題

- **曲（節回し）。** 歌詞は確定。
- **32の90秒をカットを割らずに持たせられるか。** カメラを下ろす動作と、祖父の位置。**映画の勝負所。**
- **32で祖父が来る理由を示さないのは、観客が迷子にならないか。** 30（「バッ」）の翌朝に置いているので「亮が隣に座ったから来た」と読まれる危険がある。**日を空けるか、30と32の間に何か挟むか。**
- **「起勢」の連呼。** 歌のリフレインで言ってから33で言うと萎むか。リフレインの語を変えるか、割り切るか。
- **柿が二回**（24でみなみに、25で亮に「送っといた」）。同じ言葉を誰にでも言う人として効くか。
- **「今が一番楽しい」を電話でみなみに言わせる（24）のは、狙いすぎか。** 13の夕食で亮に言うほうが自然か。
- **37で場面が多い。** 部屋／会社を一つに。
- 通しで読んで、**説明が残っていないかの検算。** 太字を全部外して読み直す。
