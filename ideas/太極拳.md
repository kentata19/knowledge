# 『起勢』（きせい）　短編映画 企画書

| | |

| タイトル | 起勢（きせい） |
| 尺 | 30分 |
| ジャンル | コメディ |
| 形式 | 実写・カラー |

---

## ログライン

「こうすればこうなる」で生きてきたエンジニアが、症状も恋人も手順で解こうとして全部失い、七十八歳で「今が一番楽しい」と言う祖母のもとへ帰る。
**条件で生きる男が、目的で生きる女に触れて、何が変わり、何が変わらないか。**

---

## 企画意図

去年、会社で声が出なくなった。
知らない人が多くいる場で発言を求められたとき。不特定多数の前で話すとき。そして、誰かの意見を否定しなければならないとき。最初の音が出ない。コンビニで「PayPayで」が言えず、現金で払う。ところが病院では全部言える。名前も日付も『北風と太陽』も。医者は「異常なし」と言った。

漢方を飲み、サウナに行き、酒でハイになれば喋れた。全部、翌朝には戻った。楽になったのは、彼女に話したときだった。何も解決していないのに。

祖母は七十八で太極拳を教えている。料理教室、フラダンス、和楽踊り。仲間がいて、「今が一番楽しい」と言う。祖父は家で新聞を読んでいて、時々、唇を閉じてから一気に開けて「バッ」と鳴らして人を笑わせる。実家に帰ると、なぜか元気が出た。なぜかは分からない。

自分は「こうすればこうなる」で生きてきた。症状も、彼女との関係も、手順で解こうとして、全部うまくいかなかった。祖母はそうやって生きていない。**この映画は、条件で生きる男が目的で生きる祖母に触れて、何が変わり、何が変わらないかを撮る。**祖母を撮りに帰るという設定は虚構だが、祖母と祖父の性格はそのままである。

## あらすじ

**起**
佐伯亮（29）はエンジニアで、世界を条件分岐で書く。声がつっかえる——知らない人の多い場で発言を求められたとき、大勢の前で話すとき、誰かを否定しなければならないとき。コンビニで「ペ、ペ、——」が出ず、現金で払う。病院ではプリントの1から10まで全部できて「異常なし」。全体会議では「で？」を五回言う社長に「そ、そ、そ——」。彼は症状をスプレッドシートに記録して再現条件を探し、自己啓発セミナーで「ステップ1〜5」を買い、恋人みなみの職場の愚痴には「①まず聞く ②否定しない ③解決案は翌日」というメモで応じる。ある夜、玄関に靴が二足ある。亮は静かにドアを閉め、外階段で「浮気 対応」を検索する。翌朝、みなみが言う。「私のこと、もうどうでもいいんでしょ」。「ち、ち、ち——」。**否定が出ない。沈黙が答えになる。**休職。彼はその休職を、タスクで埋める。コンペ応募用の企画書「祖母・78歳・太極拳」。別タブに「退職シミュレーション」。監督になれば会社を辞められる、と彼は計算している。

**承**
祖母トシ（78）は元保育園長で、玄関で抱きつき、カメラを見て髪を直す。料理教室、フラ、和楽踊り、太極拳。冷蔵庫のカレンダーは彼女の欄がびっしりで、祖父の欄は空白だ。祖父（81）は新聞とテレビ。亮を弟の名で呼び、時々「バッ」と鳴らす。朝四時四十分、トシは亮を叩き起こして公園へ連れて行く。十人の老人がラジカセで四十年前の歌を全力で歌っている。亮は三脚を立てながらドン引きし、「あんた何撮ってんの」と聞かれて「さ、さ、さ——」とつっかえる。トシはカメラに向かって全員を紹介し、亮の欲しい画を全滅させる。インタビューは「きっかけ？ なかったよ」で脱線する。祖父を「外出を促す5ステップ」で動かそうとするが、祖父は一度も断らず、ただ動かない。推手では先回りして踏ん張り、一瞬で崩される。「太極拳 効果 吃音」を検索するスマホを、トシが園児のおもちゃの手つきで取り上げる。教室で亮が何か言おうとし、大西さんが先回りして埋めにかかると、トシがその腕を推手の手つきで押さえる。全員が待つ。「み、み、水、飲んできます」。中身はどうでもいい一言だ。

**転**
取り上げられたスマホが、トシのポケットで鳴る。みなみ。トシが出る。誰か分からないまま柿の話をし、住所を聞き、「私ね、今が一番楽しいの。七十八で」と言って切る。その夜、縁側で亮はつっかえずに全部話す。トシは「お茶いれようか」と立ち上がり、「柿、送っといたから」と言って背中に触れる。亮が泣く。翌日トシはカメラを取り上げ、亮を撮る。「お昼なに食べたい」「そうめん」。亮は撮影に戻り、「もう一回、今のとこ」と祖母に指示し、トシが初めて笑わない。トシが留守の夜、祖父が鍋を火にかけたまま寝ている。亮は火を止め、手順書を閉じ、カメラを床に置き、祖父の隣でテレビを見る。「タクミ」「うん」。祖父が唇を閉じて——「バッ」。亮が笑う。推手、三回目。崩れない。

**結**
朝の公園。亮は撮っている。祖父が公園の端に立っている。亮はカメラを下ろして歌う。声が出る。祖父は見て、帰る。トシが熱を出した朝、テープが切れて歌がなくなり、全員が亮を見る。喉が閉じる。長い沈黙。「き、き、——起勢」。東京。玄関に柿の段ボール。みなみ「話が——」「知ってる」「……ずっと、なんにも言わなかったよね」「……どうしたい？」「分かんない」。復職面談で紙を渡す。「今は話せません。働けます」。彼女の物がなくなった部屋で柿を食べ、会議ではミュートのままチャットで返し、返さなくていいものを既読で置く。早朝、東京の小さな公園。セロテープで継いだテープが一拍飛ぶ。鞄のカメラは出さない。「き、起勢」。隣で、知らない老人が真似し始める。

## 何が変わり、何が変わらないか

| | 条件プログラム（亮） | 目的プログラム（トシ） |
| --- | --- | --- |
| 動機 | こうすれば治る／監督になれば辞められる | 楽しいから。仲間がいるから |
| 手つき | 質問リスト、5ステップ、スプレッドシート | 手首を取る。取り上げる。「きっかけ？ なかったよ」 |
| 他人 | 手順で扱う（みなみへのメモ、祖父への5ステップ） | 誰にでも柿を送る |
| カメラ | 撮る側にいれば喋らなくていい | 撮られる。演出する。取り上げて撮る |

**変わるもの**
- **みなみ**：手順で扱い、否定もできず、沈黙で失う → 最後に手順を出さず「どうしたい？」と問う。関係は戻らない。**問えるようになっただけ**
- **祖父**：5ステップで動かそうとする → 手順書を閉じて隣に座る。「バッ」。祖父は変わらない。**亮の側が変わる**
- **教室**：「若いの」として見られてつっかえる → 待たれる → 誰も始められない朝に、つっかえたまま号令をかける
- **カメラ**：脱出の道具 → 床に置く → 下ろして歌う → 鞄から出さない

**変わらないもの**
- 声は治らない。役割として見られれば、また閉じる
- 会社は辞めない。うまくサボる
- 祖父は家にいる。公園には二度と来ない

## 登場人物

**佐伯亮（29）** エンジニア。症状も、恋人も、祖父も、映画も、全部「手順」で解こうとする。好きで撮っていた映画は「監督になれば会社を辞められる」という脱出の条件に変わっている。本人は気づいていない。

**みなみ（28）** 亮の恋人、同棲。職場で消耗している。他の男といる。理由は亮の症状ではなく、手順で扱われることに疲れたから。悪者ではない。

**トシ（78）** 亮の祖母。元保育園の園長。料理教室、和楽踊り、フラダンス、太極拳。おしゃべりで笑顔が絶えず、人を並ばせ、連れ出し、取り上げる。撮られるのが大好きで、カメラを向けると演出し始める。助言をしない。「今が一番楽しい」。

**祖父（81）** 寡黙で真面目。家で新聞とテレビ。認知症気味で、亮を弟の名で呼ぶ。時々、唇を閉じてから一気に開けて「バッ」と鳴らし、人を笑わせる。亮の未来の形。

**太極拳教室** 大西さん（82）先回りして全部間違える／富子さん（80）誰かが休むと「死んだんじゃないの」／カンちゃん（75）元消防士、喉頭癌で声が出ない、筆談、ケロッとしている／ヨシエさん（84）四十年通って覚えていない／原さん夫婦（88・86）一言も喋らない。

## 仕掛け

**症状の規則。** 亮がつっかえるのは三つの場面だけ——知らない人の多い場で発言を求められるとき、大勢の前で話すとき、誰かを否定しなければならないとき。一対一では出ない。だから検査室では全部できて証明できない。恋人の前では流暢で、それでも本当のことを言わない。ただし彼女を否定しなければならない瞬間だけ、出ない。**観客は説明なしで、つっかえるかどうかで場面の質を読める。**

**歌うときは出る。** 全員が歌っているとき、彼一人を見ている人はいない。治癒ではない。翌朝、六人に見られて号令をかけようとすれば、また閉じる。

**敵は親切な人。** 店員は先回りして「現金ですか？」と言い、同僚は「じゃあ僕から」と引き取る。祖母だけが待つ。それは徳ではなく、園長の手癖と七十八歳の遅さ。

**推手を三回、同じアングルで。** 踏ん張って崩れる。力を抜こうとして崩れる。何も考えずに崩れない。亮の変化を測る唯一の計器。説明はしない。

**教室の歌。** トシが四十年前に作った準備運動の歌。ラジオ体操と軍歌の中間。「医者は『様子を見ましょう』で」は冒頭の医師の台詞と同じ——老人たちは四十年前から同じことを言われている。

> 朝の五時半に　起きたって／誰も褒めない　金も出ない
> 医者は「様子を見ましょう」で／薬ばっかり　増えていく
> 出るぞ出るぞ　ガタが／膝ゆるめ　腰おとせ　膝ゆるめ　腰おとせ／シャンシャン　起勢！
>
> 葬式帰りに　寿司を食う／香典返しが　また石鹸
> 息子は電話も　よこさない／嫁の悪口　言うだけ野暮
> どうせみんな　死ぬ／口はいらん　息を吐け　口はいらん　息を吐け／シャンシャン　起勢！
>
> うまくもないし　強くもない／四十年やって　この程度
> それでも今朝も　立っている／膝ゆるめ　腰おとせ
> どうせみんな　死ぬ／死ぬまで　生きる／シャンシャン　起勢！

## トーン

- 主人公の必死さを笑う。**劇中の誰も彼を笑わない。**
- 説明しない。台詞より動作。
- 劇中の映画を見せない。「夢」という言葉は誰も口にしない。
- 治らない。歌えることを回復として撮らない。
- 祖母を賢者にしない。祖父を可哀想な老人にしない。
