祖母が太極拳の先生をしていることを起点にした映画の企画メモ。

## 現在の方針

**30分の中編。コメディ。**

条件プログラム（「こうすればこうなる」）で生きた結果、彼女に見放され、症状も改善せず、仕事も回らなくなって休職する。
一人で祖母の家に行く。**条件プログラムの外側で生きている祖母に触れる。**

参照: 『川の底からこんにちは』（2010・石井裕也）— **ダサいものに全力を注ぐと人は泣く**／「中の下」の開き直り。
参照: 『生きちゃった』（2020・石井裕也）— 本当のことを言えない男と、その帰結。

## 全体を貫く一語＝「先回り If-Then」

| どこで | 先回り |
| --- | --- |
| コンビニ・会社 | **世界が彼の言葉を先回りして埋める** |
| 彼女 | **彼が彼女を先回りして手順化する** |
| 浮気 | **彼が対処法を先回りして練習する** |
| 署名・陳情 | **彼が公園を先回りして守ろうとする** |
| **推手** | **先回りした瞬間に、崩される** |

**推手は比喩ではなく、先回りを禁じる物理的な訓練である。** これで太極拳が装飾ではなく機構になる。

→ ただし先回りは**症状**であって病名ではない。病名は**〈我とそれ〉＝互いを入れ替え可能な役割として扱うこと**。店員が先回りするのは、目の前にいるのが人ではなく「客」だから。

そして同じ法則が三回起きる。

| | やること | 結果 |
| --- | --- | --- |
| **喉** | 出そうとする | 出ない |
| **彼女** | 繋ぎとめようとする | 離れる |
| **公園** | 守ろうとする | 壊れる（法化） |

**努力が原因である。** 北風と太陽であり、中動態（第847・860回）。
観客は亮より先に気づく。**必死になるほど失う。** これがサスペンスになる。

（→ 映画特集の「条件プログラムと目的プログラム（主知主義と主意主義）」は9回に登場。1260/1234/1099/1073/1021/973/886/860/847）

## 確定した設定

### 症状

**吃音的なつっかえ。** 声が出ないのではなく、最初の音が繰り返す・止まる。

「黙っている人」は考えている人にも見えるが、**つっかえる人には逃げ場がない。** 音が出ていて、全員が見ていて、本人も途中で自分を聞いている。**一回の注文が、一回のサスペンスになる。**

### 規則＝〈我とそれ〉のときだけ出る

> **互いを入れ替え可能な役割として扱っている場でだけ、つっかえる。**
> 店員と客。会議の出席者。窓口と申請者。初対面。よく知らない人が多い場。
> **家族・恋人・旧友＝〈汝〉の前では出ない。**

（[[books/我と汝]]。映画特集では第1160回で「我と汝／我とそれ」、各回に「リプレースアビリティ」）

**「先回りして言葉を埋める人」は症状であって病名ではない。** 店員が先回りするのは、目の前にいるのが人ではなく「客」だから。

**検査では何も出ない。音読もできる。歌うときも出ない。**
→ 「所見上は異常なし」がそのまま**恥**になる。何も悪くないのにできない＝自分のせい、甘え。**これが観客が握るもの。**

### この規則が映画を一本にする

| | 何が起きているか |
| --- | --- |
| **外（会社・店・区役所）** | **彼が〈それ〉にされて、声が出ない** |
| **家（みなみ）** | **彼が彼女を〈それ〉にしていて、声は出るのに何も届いていない** |

**同じ病気の裏表。彼は片方にしか気づいていない。**

彼は家では流暢である。**それでも本当のことを一度も言わない。** 沈黙は症状ではなく選択。
→ みなみの「**声のこと、言い訳にしてない？**」が、比喩ではなく**事実の指摘**になる。

### つっかえ＝関係の検出器

説明ゼロで、観客がリアルタイムに関係の質を読める。

| 相手 | |
| --- | --- |
| コンビニ・社長・飲み会・医師・区役所職員 | **つっかえる** |
| **みなみ・トシ・老犬** | **最初からつっかえない** |
| **教室** | **最初はつっかえる → 途中から出なくなる** |
| **35の号令** | **役割を占めろと求められるので、戻る** |

→ **トシは孫の名前を「ヒロシ」（息子の名）と間違える。それでも彼はつっかえない。** 名前が違っても〈汝〉であることの証明。

### 職業

**進行管理・段取り系。** ガントチャート。MGR会。**段取りの人が、段取りで壊れる。**

### 敵＝〈我とそれ〉。その見え方が「先回りして埋める」

**悪人ではなく、親切な人たち。**
コンビニ「袋——」「あ、大丈夫ですね」／会社「あ、じゃあ僕から」／飲み会「いいよいいよ、無理しなくて」。
**善意で殺される。** 彼らが先回りできるのは、相手を人ではなく役割として処理しているから。

教室が最初〈それ〉であることの印は**カテゴリー**で示す。大西さんは彼を「**若いの**」としか呼ばない。

### トシ（祖母・78）

**優しい。無条件に包摂する。ただし、何も分かっていない。**

- **言葉では何も言わない。手が優しい。** 背中に触れる、手首を取る。→ **推手と同じ回路。** 言葉を介さないから、つっかえる彼に届く
- **孫の症状に一度も触れない。** 心配も励ましも治そうともしない。ごはんを出して、手を取るだけ
- **理由を聞かない。**「なんで休職したの」「彼女とどうなの」が一切ない
- **交換しない。** 亮が「て、手伝う」と言う。トシ「いいよ」。**何もしなくても扱いが1ミリも変わらない**
- **先のことを言わない。**「これからどうするの」がない
- **賢くない。** 太極拳の効能も知らない。哲学もない。40年、毎朝やっているだけ。孫の話を聞きながら、途中で柿の話を始める

→ **聖人化の回避は「冷たくする」ではなく「賢くしない」でやる。** 優しいが、無知で、ズレている。
→ 彼は会社でも彼女に対しても**役に立つことで存在を確保してきた。トシの家ではそれが無効になる。**

### 教室の歌

トシが40年前に作った準備運動の歌。中国語っぽい擬音が混ざる。誰も意味を考えていない。カセット。伴奏は安いシンセ。
節回しは**ラジオ体操の歌と軍歌の中間**みたいな、やたら元気な長調。老人たちが**全力で**歌う。朝5時半に。声がでかい。

> **一**
> 朝の五時半に　起きたって
> 誰も褒めない　金も出ない
> 医者は「様子を見ましょう」で
> 薬ばっかり　増えていく
> 出るぞ出るぞ　ガタが
> **膝ゆるめ　腰おとせ　膝ゆるめ　腰おとせ**
> シャンシャン　**起勢！**
>
> **二**
> 葬式帰りに　寿司を食う
> 香典返しが　また石鹸
> 息子は電話も　よこさない
> 嫁の悪口　言うだけ野暮
> どうせみんな　死ぬ
> **口はいらん　息を吐け　口はいらん　息を吐け**
> シャンシャン　**起勢！**
>
> **三**
> うまくもないし　強くもない
> 四十年やって　この程度
> それでも今朝も　立っている
> 膝ゆるめ　腰おとせ
> どうせみんな　死ぬ
> **死ぬまで　生きる**
> シャンシャン　**起勢！**

**仕掛け**

- **「医者は『様子を見ましょう』で」** — シーン6で医師が亮に言う台詞と同じ。老人たちは40年前から同じことを言われている。**31で亮が初めてこれを全力で歌うとき、自分の話になる。**
- **「誰も褒めない　金も出ない」** — コンサマトリー（無償・無目的）がそのまま歌詞になっている
- **「口はいらん　息を吐け」** — 亮にだけ刺さる行。**トシは一度も説明しない**
- **「四十年やって　この程度」** — 40年通って套路を覚えていないヨシエさんに跳ね返る
- **「どうせみんな　死ぬ」→「死ぬまで　生きる」** — 居直りの核。『川の底』の「所詮みんな中の下」と同じ位置だが、軸は貧困ではなく**老いと死**
- **「膝ゆるめ　腰おとせ」** — 身体動作のリフレイン（「シジミのパック詰め」の位置）
- **「起勢！」** — タイトル回収（「川の底からこんにちは」の位置）

| 場面 | 歌い方 |
| --- | --- |
| 17（初参加） | フル。**亮は完全にドン引き** |
| 21 | 口だけ動かしている |
| 31（最後の朝） | フル。**亮が歌う。声が出る。誰も気づかない** |
| 39（東京の公園） | 三番の一行だけ、小声で |

### 推手を三回、同じアングルで

**亮の変化を測る唯一の計器。説明はゼロ。**

1. **①（19）** 構えて、読んで、踏ん張る。**一瞬で崩れる。** トシは何も言わない。次の人へ
2. **②（23）** 力を抜こうと"意識"している。顔に力が入っている。崩れる。トシが笑いながら「**まだ考えてる**」
3. **③（30）** 何も考えていない。**崩れない。数秒続く。** **トシは褒めない。** 次の人に移る

→ そして**36**、みなみの前に立つ亮は、**推手と同じ立ち方をしている。** 押し返さない。倒れない。

### 映画の動作＝「待つ」

**先回りして埋める世界の中で、待つ人だけが彼に届く。**
22で全員が待つ → 35で六人が待つ。同じ動作の反復で、規模だけが変わる。

### トーンの原則

> **亮の内面をシリアスに撮らない。彼の必死さを笑う。**
> **ただし、周りが彼を笑う場面は一つも作らない。**

観客は笑うが、劇中の誰も彼を笑わない。

- **トシ**（78）— 上記

- **富子さん**（80）— 誰かが休むと必ず「死んだんじゃないの」と言う
- **カンちゃん**（75・男）— 元消防士。号令が異様にうまかったが、**喉頭癌の手術でもう声が出ない**。筆談。ケロッとしている
- **ヨシエさん**（84）— 40年通って一度も套路を覚えていない。全部ワンテンポ遅い。**誰も指摘しない**

## 第三幕｜26:20–30:00

**35｜26:20** 朝、河川敷。トシが立てない。腰。「今日は休むわ」。

無言。**亮は押し返さない。倒れない。推手と同じ立ち方をしている。**

## 守る罠

- **治癒譚にしない。** 声は戻らない。会社も辞めない。**歌えることを「回復」として撮らない。**
- **トシを賢者にしない。** 優しさは削らない。**削るのは知恵のほう。** 効能も知らない、話も半分聞いていない、柿の話をする。
- **みなみを悪者にしない。** 疲れているだけ。**観客が両方に同情できないと成立しない。**
- **行政を悪役にしない。** 職員は親切。苦情の住民は画面に出てこない。悪人ゼロで全部が終わる。
- **太極拳を神秘化しない。** 月謝千円、文句を言う82歳、歩けなくて脱落する人。
- **劇中の誰も亮を笑わない。** 笑うのは観客だけ。
- **説明しない。** スマホを取り上げる／腕を押さえる／貼り紙。**セリフより動作。**

## 検討したが入れなかったもの

- **区民まつりのステージ** — 全力の場面は「いつもの公園の、最後の朝」でいい。祭りも観客もいらない。
- **みなみが実家に同行する案** — 一人旅にしたことで、区役所に代弁者がいなくなり（28）、最後の合唱を誰も見ていない（31）。どちらも強くなった。
- **我と汝「演説家よ、遅すぎる」** — セリフにすると映画が論文になる。
- **共同幻想論・巫女論** — トシの神秘化に直行する。
- **オデュッセイア・傷跡／寝台** — 一人旅と別れの結末になったので、認証モチーフは犬（13）だけ残した。
- **名前を間違えて呼ばれ続けるギャグ（「佐野さん」）** — 名前の間違い＝〈それ〉ではない。トシの「ヒロシ」が逆の証明になっているので撤回した。
- **自殺論・集団本位的自殺（軍隊）** — 会社を軍隊に見立てると告発の映画になる。
- **聖と俗・第6章（定住と祝祭）** — タネDを復活させるときの材料として保管。

## 残っている問題

- **曲（節回し）。** 歌詞は確定。カセットの伴奏は安いシンセで音が伸びている。
- **17でどの番から聴かせるか。** 二番（葬式・香典返し・息子）が一番強いが、初対面の情報量としては一番から入るほうが素直かもしれない。
- **31の90秒をカットを割らずに持たせられるか。** 人数、立ち位置、誰を抜くか。**映画の勝負所。**
- **36が短すぎないか。** 「知ってる」だけで足りるか、もう一息要るか。
- **観客がいつ規則に気づくか。** 8で仕込み、24で確信し、36で確定する設計。早すぎても遅すぎてもまずい。
- **大西さんの不在を、亮が知る瞬間を撮るか**（誰かが言うか、ただ位置が空いているだけにするか）。
- **「若いの」から何に変わるか。** 27でラジカセを持たされる以外に、呼び方が変わる瞬間を作るかどうか。
- 通しで読んで、**説明が残っていないかの検算。** 強調の太字を全部外して読み直す。
