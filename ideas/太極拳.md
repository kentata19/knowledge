# 太極拳（映画のタネ）

祖母が太極拳の先生をしていることを起点にした映画の企画メモ。
[[media/ビデオニュース・ドットコム/映画特集]] と `books/` の読書メモを材料にしている。回数の参照は映画特集ファイルの各回アンカーに対応。

記法: `> ` 引用 / `→ ` 自分の解釈 / `? ` 疑問

## 現在の方針

**30分の中編。コメディ。**

条件プログラム（「こうすればこうなる」）で生きた結果、症状も改善せず、仕事も回らず、彼女は他の男といる。
休職中、母に頼まれて**祖母を施設に入れる説得**のため一人で実家に帰る。
**条件プログラムの外側で生きている祖母に触れる。そして、その場所を終わらせる側に立たされる。——説得は最初から無意味だった。**

参照: 『川の底からこんにちは』（2010・石井裕也）— **ダサいものに全力を注ぐと人は泣く**／「中の下」の開き直り。
参照: 『生きちゃった』（2020・石井裕也）— 本当のことを言えない男と、その帰結。

## 全体を貫く一語＝「先回り If-Then」

| どこで | 先回り |
| --- | --- |
| コンビニ・会社 | **世界が彼の言葉を先回りして埋める** |
| 彼女 | **彼が彼女を先回りして手順化する** |
| 浮気 | **彼が対処法を先回りして練習する** |
| 祖母 | **彼が祖母を先回りして説得しようとする（スライド）** |
| **推手** | **先回りした瞬間に、崩される** |

**推手は比喩ではなく、先回りを禁じる物理的な訓練である。** これで太極拳が装飾ではなく機構になる。

→ ただし先回りは**症状**であって病名ではない。病名は**〈我とそれ〉＝互いを入れ替え可能な役割として扱うこと**。店員が先回りするのは、目の前にいるのが人ではなく「客」だから。

そして同じ法則が三回起きる。

| | やること | 結果 |
| --- | --- | --- |
| **喉** | 出そうとする | 出ない |
| **彼女** | 繋ぎとめようとする | 離れる |
| **祖母** | 説得しようとする | 動かない。**最初から決まっていた** |

**努力が原因である。** 北風と太陽であり、中動態（第847・860回）。
観客は亮より先に気づく。**必死になるほど失う。** これがサスペンスになる。

（→ 映画特集の「条件プログラムと目的プログラム（主知主義と主意主義）」は9回に登場。1260/1234/1099/1073/1021/973/886/860/847）

## 確定した設定

### 症状

**吃音的なつっかえ。** 声が出ないのではなく、最初の音が繰り返す・止まる。

「黙っている人」は考えている人にも見えるが、**つっかえる人には逃げ場がない。** 音が出ていて、全員が見ていて、本人も途中で自分を聞いている。**一回の注文が、一回のサスペンスになる。**

### 規則＝「見られながら、役割として発話するとき」

> **よく知らない人たちに見られながら、役割として何かを伝えなければならないときだけ、つっかえる。**

- **店先**（店員＋後ろの列）／**大勢の前での発表**（よく知らない人が多い場）→ **出る**
- **1対1**（検査室、二人きり）→ **出ない**
- **家族・恋人・旧友**〈汝〉→ **出ない**

根にあるのは〈我とそれ〉——互いを入れ替え可能な役割として扱う関係（[[books/我と汝]]。映画特集1160「我と汝／我とそれ」、各回の「リプレースアビリティ」）。
そこに**見られている（スペクタクルにされている）**という条件が重なったときだけ、喉が閉じる。映画特集1121の「見る・見られる／見世物＝スペクタクル」。

**「先回りして言葉を埋める人」は症状であって病名ではない。** 店員が先回りするのは、目の前にいるのが人ではなく「客」だから。

### この規則が映画を一本にする

**検査室では、全部できてしまう。**
名前も日付も、高い声の「あー」も低い声の「あー」も、『北風と太陽』も。1対1で、見物人がいないから。
→ **症状を、症状が出ない場所でしか説明できない。証明する手段がない。**
→ 「所見上は異常なし」。**だから「甘え」「気のせい」に見える。恥はここで完成する。**

| | 何が起きているか |
| --- | --- |
| **外（店・会議）** | **彼が〈それ〉にされて、見られて、声が出ない** |
| **家（みなみ）** | **彼が彼女を〈それ〉にしていて、声は出るのに何も届いていない** |

**同じ病気の裏表。彼は片方にしか気づいていない。**

彼は家では流暢である。**それでも本当のことを一度も言わない。** 沈黙は症状ではなく選択。
→ 35でみなみが言う「**ずっと、なんにも言わなかったよね**」は、症状の話ではない。**言えたのに言わなかった、という事実だけを指す。**

### つっかえ＝関係の検出器

説明ゼロで、観客がリアルタイムに関係の質を読める。

| 場面 | 見られているか | |
| --- | --- | --- |
| コンビニ（店員＋後ろの列） | ○ | **出る** |
| 検査室（1対1） | × | **出ない** |
| MGR会（大勢・よく知らない人） | ○ | **出る** |
| 新興宗教のセミナー（全員が叫んでいる） | 彼だけを見ている人はいない | **声が出る** |
| **祖母の家** | × | **一度も出ない** |
| 公園・初日（十人の前の新入り） | ○ | **出る** |
| 22 帰り際の卵焼き（二人きり） | × | **出ない** |
| **32 全力の合唱** | **全員が歌っている。彼だけを見ている人はいない** | **出ない** |
| **34 号令**（テープが切れて歌がない） | **六人に見られて、役割として発話する** | **戻る** |
| 36 復職面談（人事・上司・産業医の三人） | ○ | **出る → 紙に書いて渡す** |

→ **トシは孫の名前を「ヒロシ」（息子の名）と間違える。それでも彼はつっかえない。** 名前が違っても〈汝〉であることの証明。

### 職業

**エンジニア。条件分岐で世界を書く人。**
再現手順、チェックリスト、issue、「再現条件が特定できません」。
**すべてを if で書ける人間が、if で書けない身体を持っている。**

### 敵＝〈我とそれ〉。その見え方が「先回りして埋める」

**悪人ではなく、親切な人たち。**
コンビニ「袋——」「あ、大丈夫ですね」／会社「あ、じゃあ僕から」／窓口「あ、こちらですね」。
**善意で殺される。** 彼らが先回りできるのは、相手を人ではなく役割として処理しているから。

教室が最初〈それ〉であることの印は**カテゴリー**で示す。大西さんは彼を「**若いの**」としか呼ばない。

### トシ（祖母・78）

**優しい。無条件に包摂する。ただし、何も分かっていない。**

- **言葉では何も言わない。手が優しい。** 背中に触れる、手首を取る。→ **推手と同じ回路。** 言葉を介さないから、つっかえる彼に届く
- **孫の症状に一度も触れない。** 心配も励ましも治そうともしない。ごはんを出して、手を取るだけ
- **理由を聞かない。**「なんで休職したの」「彼女とどうなの」が一切ない
- **交換しない。** 亮が「て、手伝う」と言う。トシ「いいよ」。**何もしなくても扱いが1ミリも変わらない**
- **先のことを言わない。**「これからどうするの」がない
- **賢くない。** 太極拳の効能も知らない。哲学もない。40年、毎朝やっているだけ。孫の話を聞きながら、途中で柿の話を始める

→ **聖人化の回避は「冷たくする」ではなく「賢くしない」でやる。** 優しいが、無知で、ズレている。
→ 彼は会社でも彼女に対しても**役に立つことで存在を確保してきた。トシの家ではそれが無効になる。**

### 教室の歌

トシが40年前に作った準備運動の歌。中国語っぽい擬音が混ざる。誰も意味を考えていない。カセット。伴奏は安いシンセ。
節回しは**ラジオ体操の歌と軍歌の中間**みたいな、やたら元気な長調。老人たちが**全力で**歌う。朝5時半に。声がでかい。

**仕掛け**

- **「医者は『様子を見ましょう』で」** — シーン1で医師が亮に言う台詞と同じ。老人たちは40年前から同じことを言われている。**32で亮が初めてこれを全力で歌うとき、自分の話になる。**
- **「誰も褒めない　金も出ない」** — コンサマトリー（無償・無目的）がそのまま歌詞になっている
- **「口はいらん　息を吐け」** — 亮にだけ刺さる行。**トシは一度も説明しない**
- **「四十年やって　この程度」** — 40年通って套路を覚えていないヨシエさんに跳ね返る
- **「どうせみんな　死ぬ」→「死ぬまで　生きる」** — 居直りの核。『川の底』の「所詮みんな中の下」と同じ位置だが、軸は貧困ではなく**老いと死**
- **「膝ゆるめ　腰おとせ」** — 身体動作のリフレイン（「シジミのパック詰め」の位置）
- **「起勢！」** — タイトル回収（「川の底からこんにちは」の位置）

| 場面 | 歌い方 |
| --- | --- |
| 16（物陰から見る） | フル。**亮は完全にドン引き** |
| 21前後 | 口だけ動かしている |
| 32（最後の朝） | フル。**亮が歌う。声が出る。誰も気づかない** |
| 38（東京の公園） | 三番の一行だけ、小声で |

### 推手を三回、同じアングルで

**亮の変化を測る唯一の計器。説明はゼロ。**

1. **①（18）** 構えて、読んで、踏ん張る。**一瞬で崩れる。** トシは何も言わない。次の人へ
2. **②（25）** 力を抜こうと"意識"している。顔に力が入っている。崩れる。トシが笑いながら「**まだ考えてる**」
3. **③（29）** 何も考えていない。**崩れない。数秒続く。** **トシは褒めない。** 次の人に移る

→ そして**35**、みなみの前に立つ亮は、**推手と同じ立ち方をしている。** 押し返さない。倒れない。

### 映画の動作＝「待つ」

**先回りして埋める世界の中で、待つ人だけが彼に届く。**
21で全員が待つ → 34で全員が待つ。同じ動作の反復で、規模だけが変わる。

### トーンの原則

> **亮の内面をシリアスに撮らない。彼の必死さを笑う。**
> **ただし、周りが彼を笑う場面は一つも作らない。**

観客は笑うが、劇中の誰も彼を笑わない。

### 登場人物

- **佐伯亮**（29）— エンジニア。条件分岐で世界を書く人。**休職中。祖母を説得しに行く**
- **みなみ**（28）— 同棲。職場で消耗している。**他の男といる。理由は症状ではなく、彼の条件プログラム**
- **トシ**（78）— 上記
- **大西さん**（82）— 先回りして全部間違える。前に出すぎる。耳が遠い
- **富子さん**（80）— 誰かが休むと必ず「死んだんじゃないの」と言う
- **カンちゃん**（75・男）— 元消防士。号令が異様にうまかったが、**喉頭癌の手術でもう声が出ない**。筆談。ケロッとしている
- **ヨシエさん**（84）— 40年通って一度も套路を覚えていない。全部ワンテンポ遅い。**誰も指摘しない**
- **原さん夫婦**（88・86）— 一言も喋らない。いつも並んでいる
- **社長**（「で？」しか言わない）／**医師**／**区の職員**／同僚数名（名前は不要）

# プロット『起勢』（仮題）／約30分　第7稿

公園の法化を全部捨て、**祖母の施設入所**を軸に組み直した版。主人公が加害者側に立つ。

## 走っている装置

1. **ミッション** — 祖母を説得して施設に入れる。**エンジニアなのでスライドを作っていく**
2. **成功が喪失になる** — 教室は祖母がいなくなれば終わる。40年、彼女がラジカセを持ってきていたから。**しかも入所させないと危険なのは本当**
   → そして**説得は最初から無意味だった。** トシは亮が来る前に申し込んでいた（33で判明）。スライドも母の電話も、全部空回り
3. **観客だけが先に知っていること** — 彼の必死さが、彼女を遠ざけた
4. **締切** — 入所日＝**12月1日**／復職面談＝**12月18日**
5. **対比** — 新興宗教（ステップと料金表がある）⇄ 太極拳（何も約束しない）

## 守る罠

- **治癒譚にしない。** 声は戻らない。会社も辞めない。**歌えることを「回復」として撮らない。**
- **トシを賢者にしない。** 優しさは削らない。**削るのは知恵のほう。** 効能も知らない、話も半分聞いていない、柿の話をする。
- **みなみを悪者にしない。** 疲れているだけ。**観客が両方に同情できないと成立しない。**
- **新興宗教を嘲笑しない。** 亮は本当に救われかけている。**インチキだから効かないのではなく、ステップがあるから効かない。**
- **太極拳を神秘化しない。** 月謝千円、文句を言う82歳、歩けなくて脱落する人。
- **劇中の誰も亮を笑わない。** 笑うのは観客だけ。
- **説明しない。** スマホを取り上げる／腕を押さえる／PCを閉じる／ラジカセを渡す。**セリフより動作。**

## 検討したが入れなかったもの

- **公園の許可制・署名・区役所（法化のくだり全部）** — 冗長。外敵との戦いは主人公の内側に葛藤を作らない。**亮自身が教室を終わらせる側に立つ**構造に置き換えた。あわせて共同幻想論の「禁制と黙契」、自殺論の「危機は統合を強める」も落ちた。
- **自力対処のモンタージュ** — 各場面に散らした（5の新興宗教／7のスプレッドシートと漢方／6の翌日）。
- **河原で絶叫して通報される** — 削除。新興宗教に置き換え。
- **老犬** — 削除。
- **トシが風呂場で転ぶ** — 削除。「転んだ→だから施設」は、脚本自身の条件プログラムになる。危険の証明は焦げた壁と、火をかけたまま寝ている28で足りる。
- **トシの「……行くよ」** — 削除。説得の結果に見える。**亮が来る前から申し込んでいた**（33）に置き換え、因果を切った。
- **名前を間違えて呼ばれ続けるギャグ（「佐野さん」）** — 名前の間違い＝〈それ〉ではない。トシの「ヒロシ」が逆の証明になっている。
- **飲み会**（生成AI／新NISA／人格5類型） — 第一幕が重くなりすぎる。7のスプレッドシートが「すべてを手順で解こうとする」側から引き受ける。
- **区民まつりのステージ** — 全力の場面は「いつもの公園の、最後の朝」でいい。
- **オデュッセイアの寝台・傷跡** — 別れの結末になったので落とした。

## 残っている問題

- **曲（節回し）。** 歌詞は確定。カセットの伴奏は安いシンセで音が伸びている。
- **32の90秒をカットを割らずに持たせられるか。** 人数、立ち位置、誰を抜くか。**映画の勝負所。**
- **柿が二回**（23でみなみに、24で亮に）。同じ言葉を誰にでも言う人、として効くか、くどいか。
- **33の「先月お申し込み」で、母も知らなかったことになる。** トシが誰にも言っていなかった、で通るか（「先のことを言わない」と整合はする）。
- **34で教室が続くのか終わるのか**を示すか、示さないか。
- **35の「どうしたい？」が、まだ少し綺麗すぎるかもしれない。**
- **16で亮が動画を撮る**のは、やりすぎか（説得材料集めの可視化としては強いが、感じが悪すぎる可能性）。
- **19（祖母にスライドを見せる）と24（縁側）が流暢なぶん、第二幕の前半につっかえが少なくなる。** 教室のシーン（17・21）で足りるか。
- 通しで読んで、**説明が残っていないかの検算。** 太字を全部外して読み直す。
